## 1. 认识主界面

总控台是右侧栏的一个标签页，**不在独立页面**。安装并重启宿主后，在右侧栏找到「总控台」标签即可打开；打开时默认落在「概览」页。标签条从左到右共六个标签：

| 标签 | 用途 |
|---|---|
| 概览 | 只读汇总：是否需要你处理、谁在跑、今天与近 7 天的数据 |
| 审批 | 看待你决策的审批，选择选项 / 写答案 / 跳过并提交 |
| 工单 | 按阶段浏览工单，点开进入详情 |
| 事件 | 看到达 Router 的输入及其结局，搜索覆盖全量历史 |
| 来源 | 查看 / 开关 / 测试 / 删除感知来源 |
| 设置 | 编辑派单规则、决策权限、执行器与提示词 |

「审批」标签上带一个红色待审批数徽标，超过 99 显示 `99+`。工具栏最右侧的「帮助」按钮会按当前页面给出说明；概览页与设置页没有帮助按钮。

**语言**：界面中文 / 英文词典齐备，跟随 DSH 的语言设置自动切换，面板内没有单独的语言开关。

## 2. 概览

概览回答三个问题：系统是否活着、需要你做什么、谁在跑。

<!-- 配图占位：概览页，标注状态脉搏、注意力条、进行中列表 -->
<p align="center">
  <!-- 配图占位：概览页核心区域 -->
  <img src="" width="100%" />
</p>

- **状态脉搏**：显示「运行中 / 感知中 / 空闲」，Router 未就绪时显示「Router 会话未就绪」；右侧是「最近活动」时间。点击可打开 Router 会话。数据连接失败时提示「数据可能已过期」。
- **注意力条**：把最需要你处理的事排在前面，最多显示 2 条，其余折叠为「另有 N 项」。条目类型包括：审批（「N 条审批等你处理」，附「已等待 N 分钟」与「最高风险」）、来源（「N 个感知来源异常 · 可能漏掉变化」）、工单（「N 张工单已中断」「N 个执行会话不在线」「N 个执行会话上下文 ≥80%」）。点条目跳到对应标签或会话。
- **进行中**：列出执行会话及上下文占用，显示「占用 / 最大槽位」与「排队 N」；超过 5 行时可用「还有 N 个执行会话」跳到工单页。每行可点「打开执行会话」。
- **今天**：三格只读统计——审批（「已处理 N · 待 N」）、工单（「完成 N · 失败 N」，悬停看平均耗时）、事件（「投递 N · 过滤 N」）。这三格不可点击。
- **过去 7 天的活动**：按天堆叠「投递 / 过滤」，空态提示「过去 7 天没有事件」。
- **底栏**：累计工单 / 审批 / 事件数与运行中的来源、定时数量，纯文本不可点击。

> 全新空态下会提示「还没有任何活动」，并给出「去来源页」按钮，或让你先和 Router 说一句话。

## 3. 审批

审批是唯一需要你动手的地方。工具栏有「待审批 / 已通过 / 全部」三个筛选胶囊、搜索框与帮助按钮。

<!-- 配图占位：审批页，展示待审批卡片展开后的选项与附件 -->
<p align="center">
  <!-- 配图占位：审批操作面板 -->
  <img src="" width="100%" />
</p>

1. 在「待审批」胶囊下找到目标卡片，点右侧「展开」。
2. 展开后可看到完整题干、「风险」（低 / 中 / 高），以及「请选择一个选项」的单选组。也可以只在「输入你的答案」里写文字。
3. 有多条附件时显示「附件」区，点文件名可在右侧栏打开——**附件只能看，不能改**。
4. 点「提交」完成决定；不想处理可点「跳过」。

**决定的规则**（按优先级）：显式点「跳过」→ 已跳过；没选选项但写了文字 → 以文字作为答案；选了选项 → 按所选；**什么都不填直接提交也等价于跳过**。你写的文字会随任何决定一起送达。

提交后的提示分两种：「决定已送达，执行会话继续」表示会话仍在等待、直接收到你的决定；「决定已保存，执行会话已唤醒」表示会话原本已停止，决定已保存并把它唤醒。

> 已处理的审批到「已通过」胶囊查看，卡片变为只读，能看到当时的答案与时间，不再显示选项和提交按钮。点「跳转会话」可打开对应执行会话。

**筛选是隐藏，不是置灰**：切换胶囊或搜索会把不匹配的卡片从列表移除，并显示「没有匹配的审批」等空态；搜索词与筛选是交集关系。

## 4. 工单与工单详情

### 4.1 工单列表

工单页有「待处理 / 进行中 / 已结束 / 全部」四个筛选胶囊，默认「进行中」。注意：**「进行中」包含阻塞中与已中断的工单**，它们仍占着执行槽位。点整行卡片进入详情。

### 4.2 工单详情

详情页覆盖同标签的列表页，不另开标签。

<!-- 配图占位：工单详情页，展示交接时间线与交付区 -->
<p align="center">
  <!-- 配图占位：工单详情核心区域 -->
  <img src="" width="100%" />
</p>

- **头部**：「返回工单列表」（返回后胶囊与搜索词保留）、工单短码、阶段标签、「打开会话」按钮（尚未创建会话时禁用），以及负责人、Agent 数、交接次数与时长。
- **交接时间线**：一次委派就是一次交接。可在「泳道 / 事件流」两种视图间切换；泳道按 Router / 你 / Worker / 子代理分行，点一行不算跳页，而是展开全文与 from → to（最多两个会话入口）。可「聚焦」某个 Agent。
  - 行类型包括：派发、追加、补充、委派、上报、同步、审批、决定、介入、排队、中断、恢复、结束、失败、作废，以及进行中的「Live」行。
  - 会话日志不可读时显示「会话日志不可读，仅显示账本事实」；日志不完整时提示「部分投递可能缺失」。
- **交付**（默认折叠，工单结束且有汇报时自动展开）：显示原因、汇报、指标（轮次 / 交接 / 时长 / token），可「复制」全文。尚未汇报显示「尚未汇报」。
- **会话与目录**：列出负责人、子代理、工作目录与会话 id；尚未派发时显示「尚未创建会话」。

> 工单页与详情页都是**只读**的——派单与补充是 Router 通过对话调用的工具，不能在面板里操作。

## 5. 事件

事件页按输入类型看「到达 Router 的输入」及其结局。

- **两个下拉**：「事件类型」（全部类型 / 用户 / 定时 / 感知）与「处理方式」（全部处理 / 派发 / 追加 / 补充 / 响应 / 忽略（过滤））。
- **结局徽标**：待处理、已过滤（可附「不匹配 / 节流 / 无变化」原因）、派发 / 追加 / 补充（带工单短码）、响应。回合结束时没有显式处理动作的信号标为「推断」，悬停有说明。带工单的徽标可点，直接打开对应工单。
- **来源行**：用户消息显示「对话」，其余显示「来源 · 线程」。
- **搜索**：在搜索框输入，停 250ms 后检索**全部历史**（不只是最近的快照），输入时显示「正在检索历史…」；输入过程中旧的检索会被取消。

> 「忽略（过滤）」表示信号被感知规则的过滤步骤挡下、没有投递给 Router；这不等于工单失败。

## 6. 来源

来源页管理**感知来源**：让 Agent 在你不在场时也能收到通知。

<!-- 配图占位：来源页，展示来源卡片与线程开关 -->
<p align="center">
  <!-- 配图占位：来源操作面板 -->
  <img src="" width="100%" />
</p>

- 渠道分「内部事件 / 本地文件 / 脚本」；状态分「运行中 / 已停止 / 错误」。卡片显示线程数与「最近触发 / 尚未触发」。
- **开关**：开关来源或某条线程。操作是即时生效的：先本地更新，失败会自动回滚并提示「切换失败，已恢复原状态」。线程关闭后不再产生、也不记录该类信号。
- **测试**：点「测试」会真实投递一条测试候选，结果以「最近信号」列出；没有结果提示「测试没有产生新信号。」。
- **重启**：仅在状态为「错误」时出现，实际是重新启用该来源。
- **删除**：需二次确认，弹窗说明「删除后不再感知；历史信号仍保留在事件页。」。已删除的来源不会重复删除失败。
- **创建**：来源只能**在对话中**创建——点「在对话中创建」会跳到 Router 会话，然后说「盯着……有变化就告诉我」（没有 Router 会话时该按钮禁用）。面板内不能编辑来源的路径、事件或脚本命令。

> 定时任务由宿主的自动化任务页负责，这里不重复展示，只在概览底栏显示数量；本插件不创建也不修改定时任务。

## 7. 设置

设置分三段：「派单规则 / 执行器 / 提示词」。有改动才出现保存条，可「撤回」或「保存」；保存成功提示「设置已保存」。

### 7.1 派单规则

- 「派单规则」只进入 Router 提示词，决定什么该交给执行会话；**只有启用的规则生效**。
- 「决策权限」只进入 Worker 提示词，说明什么该提交审批、什么可以自己决定。
- 两组共用同一版本号，一起保存。可「添加规则 / 添加权限」「删除规则 / 删除权限」，最多 50 条；名称与说明不能为空，名称最多 40 字、说明最多 500 字。
- 名称与说明完全相同的两条会被判为重复；换行会被压成空格，一条规则只能占一行。

### 7.2 执行器

- 「执行器模型」可分别选服务商、模型与推理强度（可选），或「继承 DSH 默认值」。这里的配置**只影响之后新建的执行会话**，不改动正在跑的会话。
- 「并行工单数」范围 1–100，默认 5。**改小不会中断已在执行的工单**，只限制之后的派发。
- 「执行环境根目录」留空则用默认目录；填写必须是绝对路径。

### 7.3 提示词

- 三份文本：「共享约定」「Router 角色」「Worker 角色」，共享约定同时进入两个角色。
- 三个子页：「编辑 / 完整提示词 / 历史」。「完整提示词」可按角色查看，并与默认比较、复制全文。
- 「历史」列出已保存版本；「查看」只读，「载入编辑器」把旧版本放进编辑器。**载入后还需要点「保存」才会生效**。
- 每份提示词最多 32000 字符，不能为空。

> 保存时若提示「设置已在别处更新，已载入最新版本」，说明版本在别处被改过；提示「输入不合法，请检查后再保存」则按上面的字段规则修正。

## 8. 常见操作问题

- **审批提交后 Worker 没反应？** 看提交提示：「决定已送达」表示会话正在等待、应立即继续；「决定已保存，执行会话已唤醒」表示原会话已停止、已被唤醒。若目标会话已归档，决定会被作废，需重新派单。
- **为什么这条信号是「已过滤 / 忽略」？** 感知规则在投递前做了过滤（不匹配 / 节流 / 无变化），没有惊动 Router。到来源页检查线程开关与配置。
- **工单显示「阻塞中」是什么意思？** 它在等你的审批，且仍占着执行槽位；到审批页处理即可放行。
- **找不到更早的信号？** 快照只带最近 200 条，在事件页搜索框输入关键词可检索全量历史（单次最多 500 条）。
- **改了执行器模型，当前工单没变？** 执行器设置只影响之后新建的会话；已运行的工单沿用创建时的模型。
- **载入历史提示词后没生效？** 载入只是放进编辑器，必须再点「保存」。
- **来源开关失败？** 系统会自动恢复原状态并提示，稍后重试；持续失败可到设置或对话中检查来源配置。

遇到无法解决的问题时，记录当时情况再复现一次（如果可以），然后在 issue 中提出；擅长定位与修改代码的也欢迎提交 PR。
