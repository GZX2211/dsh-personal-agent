# 工单详情页开发方案 v2

> 2026-11-22。此文件是工单详情页后续实现的唯一依据；旧详情页方案归档后不再参照。
>
> 设计稿（视觉与 DOM 参考）：`collab/scr/ticket-detail-v2.html`
> 静态预览：`collab/img/ticket-detail-v2.png`

## 1. 目标与范围

### 1.1 目标

在右侧栏 540px 内实现一张工单的详情页，核心是**交接时间线**：

- 时间从上往下；
- 默认三主轨 **Router → 你 → Worker**，子代理在 Worker 右侧；
- 左侧画泳道与交接线，右侧只显示**类型徽标 + 简写时间**；
- `from → to`、摘要、完整时间放在悬停 tip；
- 点击行或节点**就地展开**全文与会话定位，不跳页、不开第二个面板；
- 支持子代理很多时的折叠、聚焦与手动切换事件流。

### 1.2 范围

**做：**

- 详情页入口、返回、轮询与状态；
- 三主轨、子代理泳道、窄列缩写、`+N` 折叠、聚焦、事件流；
- 直线连线、类型体系、行展开、下游高亮、Live 行；
- 交付折叠、会话与目录折叠；
- 为满足以上 UI 需要的后端少量补充（三轨、介入行、Live 多 Agent）。

**不做：**

- 独立「汇报」类型；汇报只放交付区；
- User → 子代理的介入消息（本次只做 User → Worker）；
- 事件流自动切换、阈值提示；
- 右侧信息面板、影响树、收到后做了什么；
- 结构视图 / 拓扑视图；
- 真实时间比例轴（时间线采用等距行）。

## 2. 页面结构

### 2.1 入口与容器

- 工单列表整行点击进入详情；详情覆盖列表，返回保留当前胶囊与搜索词。
- 详情位于现有 `工单` tab 内，tab strip 本身不动；头部提供 `‹ 工单 #短码`。
- 面板宽度 540px，高度随宿主；内容纵向滚动。
- 头部只保留：短码、阶段、标题、负责人、Agent 数、交接数、时长、`打开会话`。

### 2.2 区块

```
头部
├ 交接时间线
│  ├ 卡头：标题 + 交接数/并行数
│  ├ 来源行（感知/用户/定时 + 文本 + 时间）
│  ├ 泳道标签行（sticky）
│  ├ 交接行 / 里程碑行
│  └ Live 行（当前进行中）
├ 交付（默认折叠）
└ 会话与目录（默认折叠）
```

- 来源行不占交接行，不参与计数。
- 交付区：状态、汇报全文、结果、指标（轮次 / 交接 / 时长 / token）。
- 会话与目录：负责人、活跃子代理、工作目录、会话 id。
- 没有独立卡片放审批、来源、中断：它们都并入时间线。

## 3. 泳道规则

### 3.1 顺序与常驻

固定顺序：

0. **Router**（`id='router'`）
1. **你 / User**（`id='human'`）
2. **Worker / 负责人**（真实 session id；排队时占位 `id='worker'`）
3. 子代理（按 catalog 创建顺序；父级在左、子级在右）

- Router、User、Worker **永远存在**，即使没有审批、没有子代理。
- 排队中还没有 Worker 会话：Worker 列显示占位，状态「待放行」，不画派发线。
- 没有子代理时，Router → Worker 的派发线仍然让三轨有流动。

### 3.2 全名 / 缩写

- **全名模式**：显示名称 + 第二行角色（例如 `Router / 路由`、`reviewer / 子代理`）。
- **缩窄模式**：名称取**前两个字母或汉字**（`Array.from(name).slice(0, 2)`），隐藏第二行角色；悬停显示完整名称、角色、状态、轮次。
- 是否缩写由容器宽度决定：
  - `available = cardInnerWidth - metaMinWidth`（meta 至少容纳徽标 + 时间，约 96px）；
  - `fullLaneWidth` 按最长泳道名自适应，44–60px（A 示例 60，C/D 示例 44）；
  - `fullWidth = pad*2 + (visibleLanes-1) * fullLaneWidth`；
  - 若 `fullWidth > available` 则进入缩窄：列宽 32、前两个字符、隐藏角色；
  - 若缩窄后仍放不下，才进入 `+N` 折叠；v1 默认最多 4 个子代理列。
- 缩写不改变 hover 文案，也不改变行内 `from/to` 数据。
- 中文名只有一个字时保留一个字（例如「你」）。

### 3.3 子代理很多时

- 默认只显示**有活动或与主轨有通讯**的子代理，最多 4 列；其余折叠为 `+N`。
- `+N` 是一个真实占位列，表示 N 条安静泳道；展开后进入横向滚动（v1 可先只展示折叠态）。
- 点击泳道标签进入「只看这个 Agent」：只保留该 Agent 与直接上下游，其他行淡化；再点取消。
- 用户需要时手动切「事件流」；**不自动切、不设阈值、不弹提示**。

## 4. 类型体系

### 4.1 细类徽标

| 粗类 | 细类 | 说明 |
|---|---|---|
| 任务 / 派发 | 派发 | Router → Worker 新派工单 |
| 任务 / 派发 | 追加 | Router → Worker 追加工单 |
| 任务 / 派发 | 补充 | Router → Worker 转发新事实 |
| 通信 | 委派 | 父 Agent → 子 Agent 派活（含 fan） |
| 通信 | 上报 | 子 Agent → 父 Agent |
| 通信 | 同步 | 兄弟 Agent 之间 |
| 审批 | 审批 | Worker → User 提交审批 |
| 审批 | 决定 | User → Worker 的审批结果 |
| 介入 | 介入 | User 绕过 Router 直接给 Worker 发消息（虚线） |
| 状态 | 排队 / 中断 / 恢复 / 结束 / 失败 | 里程碑，无连线 |

- **没有「汇报」类型**；汇报只在交付区。
- 颜色：派发紫蓝、补充青、委派紫、上报青绿、同步灰蓝、审批橙、决定绿、介入灰白虚线、状态灰、失败红。
- 连线颜色跟随**发送方身份色**；节点/徽标颜色跟随**类型色**。
- 类型文案全部走 i18n，不在组件里拼中文。

## 5. 行与交互

### 5.1 行结构

```
[rail: 泳道基线 + 发送点 + 直线 + 箭头 + 接收节点] [meta: 类型徽标 + 简写时间]
```

- 行高：普通 32px；fan 46px；里程碑 26px；live 30px。
- 右侧**不显示** `from → to`、摘要、完整时间。
- 时间简写：当天 `09:18`；跨天 `昨天 09:18` / `11-21 09:18`；悬停完整 `2026-11-22 09:18:22`。
- 连线一律**直线**（`<line>`），不用曲线；跨列时水平穿过中间列，中间列无节点则不影响阅读。
- 发送方一个小点；接收方一个 16px 圆角方块，边框=类型色；虚线用于介入；fan 在同一行画多个接收节点与箭头。
- 里程碑：目标泳道上的空心圆点，无连线。
- Live 行：见 §5.5。

### 5.2 悬停

- 行/节点悬停显示 tip：`from → to`、细类、摘要（1 行）、完整时间。
- 时间单独悬停只显示完整时间。
- 使用宿主 Tooltip；不在行内放隐藏文本块。

### 5.3 点击展开

- 点击整行、节点或连接线都触发展开；键盘 Enter / Space 同样；Esc 收起。
- 展开区**全宽**，位于该行下方：发送方 → 接收方、类型、完整时间、全文、两个「在会话定位」按钮（仅当有 sessionId）。
- 不展示影响树、不展示「收到后做了什么」。
- 展开行高亮；同一时间只展开一条。

### 5.4 下游高亮

- 选中一条交接后，高亮该接收方的**紧接着的下一步动作**：
  - 从选中行之后扫描；
  - 若 `row.from` 属于选中行的接收方，加入高亮；
  - 遇到第一条来自其他发送方的交接行就停止；
  - 里程碑不打断扫描；
  - 选中里程碑 / Live 不产生高亮。
- 纯函数 `downstreamIdsOf(rows, selectedId)`，可单测。

### 5.5 Live 行

- 位置：时间线末尾，仅在工单未结束且存在运行中 Agent / 等待审批时出现。
- 每个可见的运行中 Agent 在各自泳道画一个绿色脉冲点。
- 文案是**当前活动**：取该 Agent 最近一条 assistant 文本的首行；没有文本时回退「第 N 轮」。
- 单个 Agent：直接显示。
- 多个 Agent：文案轮播（约每 3 秒滑动切换），展示每一条「等待中 · 活动」；`prefers-reduced-motion` 时只显示第一条。
- 等待审批：不显示绿点，显示「等待审批 · 问题摘要」，等待对象=用户。
- 没有运行中 Agent：显示「等待中 · Worker 第 N 轮」。
- Live 的轮播只针对**可见泳道**；折叠的安静子代理不参与。

### 5.6 事件流

- 卡头提供 `泳道 / 事件流` 手动切换，不自动。
- 事件流每行：时间、类型徽标、`from → to`、摘要；点击就地展开全文与定位。
- 事件流只列交接行（含介入）；里程碑与 Live 留在泳道视图。
- 事件流是规模化降级视图；不改变任何数据。

## 6. 数据与后端

### 6.1 现有接口

`GET /personal-agent/api/tickets/:id` 返回 `TicketDetailResponse`：

```ts
{
  ticket: TicketView
  mode: TaskMode
  origin: DetailOrigin
  lanes: AgentLaneView[]
  rows: ChainRow[]
  delivery: TicketDeliveryView
  metrics: TicketDetailMetrics
  completeness: { logs: DetailLogState; reason?: string }
  generatedAt: number
}
```

### 6.2 泳道常驻

修改 `buildLanes()`（`src/host/projector/ticket-detail.ts`）：

- 永远返回 `router`（index 0）与 `human`（index 1）；
- 有 `workerSessionId` 时 Worker 用真实 session id，index 2，role `lead`；
- 排队中没有 Worker 会话时返回占位 `{ id: 'worker', index: 2, role: 'lead', status: 'idle' }`；
- 子代理 index 3+，父级在左、子级在右；
- `metrics.agents` 只统计有 sessionId 的 lead / subagent，排队中的占位 Worker 不计。

### 6.3 介入行

在共享契约 `src/shared/ticket-detail.ts` 增加：

```ts
export interface InterveneRow extends ChainRowBase {
  kind: 'intervene'
  from: 'human'
  to: string // Worker session id
  summary: string
  text: string
  anchor: { sessionId: string; seq?: number }
}
```

并加入 `ChainRow` union。

`messageRow()` 规则：

- 只处理 `sessionId === ticket.workerSessionId` 的根 Worker 会话；
- `event.type === 'user/message'` 且 `message.source.kind === 'user'`；
- 文本非空；
- 工单已结束（`endedAt` 存在）时，`event.time >= endedAt` 的不记录；
- 插件投递（`dsh-personal-agent`、`dsh-personal-agent/perception`）、Agent 投递（`agent-message`）、审批结果消息都不算介入；
- `summary` = 首行 120 字，`text` = 4000 字上限，`anchor` = `{ sessionId, seq }`；
- 用户直接给子代理发消息**不记录**。

### 6.4 Live 多 Agent

扩展 `LiveRow`：

```ts
export interface LiveAgentView {
  lane: string
  activity?: string
  turn?: number
}

export interface LiveRow extends ChainRowBase {
  kind: 'live'
  lane?: string
  live: LiveState
  waitingOn?: string
  turn?: number
  liveAgents?: LiveAgentView[]
}
```

`buildLive()`：

- 未决审批：`live: 'waiting-approval'`，`lane: 'human'`，`waitingOn` 为提问方；不生成 `liveAgents`；
- 有运行中 Agent（lead / subagent，status `running`）：`live: 'running'`，`liveAgents` 列出全部运行中 Agent；
- 没有运行中 Agent：`live: 'waiting-agent'`，`waitingOn` 为 Worker；
- 已结束：不返回 Live 行（保持现状）。

活动文本 `activity`：

- 从该会话窗口内反向扫描 `assistant/message`，取第一条非空文本的首行（80 字）；
- 没有 assistant 文本时留空，客户端用 `turn` 回退「第 N 轮」；
- 后端只返回原文，不生成 UI 句式；「等待中 · ...」由客户端 i18n 拼装。

### 6.5 交接计数

客户端纯函数 `handoffCount(rows)`：

- 统计 `dispatch`、`supplement`、`spawn`、`hop`、`fan`、`approval`、`intervene` 行；
- `fan` 算一次事件（不是按目标数）；
- 头部与卡头共用；不改现有 `metrics.hops` 语义。

### 6.6 其他

- 不新增事件类型；`task/*` 账本事件不变。
- 介入行只存在详情视图，不写账本。
- 交付契约保持 `report / outcome / reason`；验收标准已不在详情中显示。
- 会话窗口已按 `start/end` 裁剪；介入额外用 `endedAt` 严格截止。

| `src/client/style.ts` | 详情页样式与身份色/类型色 |

### 7.2 布局与测量

- 使用 `ResizeObserver` 测量时间线卡内容宽度；
- 计算 `visibleLanes`（Router/User/Worker + 最多 4 个子代理 + `+N`）；
- 按 §3.2 决定全名/缩写（全名列宽 44–60px 自适应，缩写 32px）；
- 泳道 x 坐标 = `pad + i * laneWidth`；行与标签共用同一组坐标；
- 所有连线由 SVG 绘制，行本身是 HTML `button`；
- 面板 540px 下默认不出现横向滚动；展开 `+N` 后才允许横向滚动。

### 7.3 状态

- `selectedRowId`：展开行；
- `focusedLaneId`：聚焦；
- `viewMode: 'swim' | 'stream'`；
- 折叠区是否展开（交付 / 目录）；
- 轮询：queued/running 2s；ended 只刷新一次或 60s；
- 用户已向上滚动时新行不抢滚动，显示「↓ N 条新交接」。

### 7.4 轮播

- 多个 `liveAgents` 时使用 CSS transform 轮播，3–4s 一轮；
- 单条不轮播；
- `prefers-reduced-motion` 下只显示第一条；
- 轮播文本是 i18n 模板 + 后端 `activity`，不在组件里写死具体活动。

### 7.5 键盘与可访问性

- 行：`tabindex=0`、Enter/Space 展开、Esc 收起；
- 泳道标签：button，可聚焦、可点击；
- 展开区与行用 `aria-expanded` / `aria-controls` 关联；
- 连线与节点 `aria-hidden`，语义由行文本提供；
- 类型徽标与时间有可读的 aria-label。

### 7.6 视觉

- 背景/边框/文字用宿主 alias：`bg-layer-1/2`、`border-l2`、`label-primary/secondary/tertiary`；
- 身份色 5 + 人类灰；类型色见设计稿 CSS 变量；
- 行 hover 3% 白，选中 7% 蓝；下游行左侧 2px 蓝条；
- 无官方 Tag 塞入行内；行内组件全部自绘，避免带进不属于图的字号与内边距。

## 8. 页面状态

| 状态 | 表现 |
|---|---|
| 排队中 | 三轨 + Worker「待放行」；排队里程碑；不画派发线；0 次交接 |
| 进行中 | 正常时间线 + Live；定时轮询 |
| 已结束 | 无 Live；结束/失败里程碑；交付区展开可读汇报 |
| 日志不可读 | 提示条；只显示账本行（派发/补充/审批/里程碑），无会话投递 |
| 空 | 「还没有交接」；仍显示三轨与来源 |
| 404 | 返回列表，提示工单不存在 |

## 9. 测试

### 9.1 后端

- 全名/缩写判定（宽度边界、中文/英文、`+N`）；
- 前两个字符缩写规则（code point，不是 UTF-16 切割）；
- 时间简写（当天/昨天/跨年）；

- `handoffCount`（含 fan 计一次）；

### 9.3 UI / 集成

- 列表 → 详情 → 返回保留胶囊/搜索；
- 展开/收起、聚焦、事件流切换、折叠；

## 12. 风险与决策记录

- **活动文案质量**：依赖 assistant 文本；没有文本时只能回退轮次。实现时先按首行，后续可加工具名/步骤。
- **多个 Live 的规模**：轮播只针对可见泳道；折叠的安静 Agent 不参与，避免轮播 50 条。
- **缩写阈值**：以实际测量为准；阈值变化不应改变行数据，只改变标签与列宽。
- **50–100 子代理**：默认 `+N` 保持窄栏可读；展开依赖横向滚动；事件流是用户主动选择的降级。
- **下游高亮**：只做「接收方紧接着的下一步」，不是完整因果推断；避免引入不可靠的归因。
- **无旧方案依赖**：本文件自包含；旧详情页方案归档后不再作为实现依据。
