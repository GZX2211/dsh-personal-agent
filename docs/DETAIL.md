# dsh-personal-agent

个人代理（Personal Agent）把你的任务拆成工单，交给独立的执行会话跑，并且只在**需要你决定**的时候停下来等你。

## 它现在的状态

当前是 **P2 工具与会话**：宿主侧闭环已经可用——路由会话能把任务派成工单、调度器按并发名额放行、执行会话可以提交审批并阻塞等待、回合结束会自动汇报并结束工单、审批决定支持三支路送达与启动自愈。**总控台面板的审批页与工单页仍无数据**，卡片、筛选与搜索在 P3 实现；四个未实现的标签页显示「暂未开放」。

## 它怎么用

1. 打开任意会话，右侧栏的指南页会出现「个人代理」卡片。
2. 选择卡片（或从标签栏打开）进入总控台。
3. 顶部六个标签页：概览、审批、工单、事件、来源、设置。

## 已实现的入口

| 入口 | 位置 |
|---|---|
| 总控台标签页 | 右侧栏，标签名「总控台」 |
| 指南卡片 | 右侧栏指南页 |
| 健康检查 | `GET /personal-agent/api/health`（同源） |
| 总控台快照 | `GET /personal-agent/api/snapshot`（同源 + 自定义头，供面板读取） |
| 审批决定 | `POST /personal-agent/api/approvals/:id/decide`（同源 + 自定义头） |
| Agent 工具 | `pa_task_route`、`pa_ledger_query`（路由会话）；`pa_approval_submit`（执行会话） |

## 已知限制

- 概览、事件、来源、设置四个标签页暂未开放。
- 审批页与工单页目前为空，没有卡片、筛选与搜索。
- 无桌面通知、无外部事件源、无定时事件。
- 同一 profile 只支持单进程运行。
